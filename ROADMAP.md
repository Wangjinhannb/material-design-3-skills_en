# Roadmap

- Seven-platform Reference App projects.
- Seven-platform 31-component catalogs.
- Web accessibility and visual regression.
- Android, iOS, Windows, GTK, and Qt build CI.
- HarmonyOS project structure and static validation.

- Stable variant, state, accessibility, and visual coverage for all 31 components on every stable platform.
- Stable release workflow, compatibility matrix, and migration guide.
