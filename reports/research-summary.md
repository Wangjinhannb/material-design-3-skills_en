# Research Summary

Sources: `metadata/sources.yaml`.

- Android Compose Material 3 is an official M3 implementation reference; current packages also include Expressive APIs.
- `@material/web` is in maintenance mode and remains optional.
- ArkUI, SwiftUI, WinUI 3, GTK/libadwaita, and Qt provide platform UI primitives. Classic M3 styling is mapped separately.
- DTCG 2025.10 is used for the color-token structure.
- WCAG 2.2 and WAI-ARIA APG are used for Web accessibility checks.

Retrieval dates and source status are stored in metadata.
