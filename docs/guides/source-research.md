# Source Research Guide

Use first-party documentation or standards bodies for normative and version-sensitive claims.

## Preferred sources

- Google Material Design and Android Developers;
- Huawei Developers for HarmonyOS/ArkUI;
- Apple Developer documentation;
- Microsoft Learn for WinUI and Windows App SDK;
- GTK/GNOME and Qt documentation;
- W3C/WAI for web accessibility;
- Design Tokens Community Group reports for token interchange.

Record the source ID, title, organization, URL, retrieval date, status, role, and license/usage note in `metadata/sources.yaml`.

When current documentation mixes Classic M3 and Material 3 Expressive, keep the rule out of the normative Classic baseline until its status is clear.
