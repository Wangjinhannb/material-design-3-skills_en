# Normative Language

The repository uses RFC-style keywords in normative rules and AI-execution guidance.

- **MUST** — required for this baseline or workflow.
- **MUST NOT** — prohibited.
- **SHOULD** — expected unless a documented platform constraint justifies another choice.
- **SHOULD NOT** — normally avoided; exceptions require a reason.
- **MAY** — optional.

A keyword expresses repository conformance unless the surrounding text explicitly attributes the rule to an upstream source.
