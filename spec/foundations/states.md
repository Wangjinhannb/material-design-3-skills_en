# Interaction States

Provenance: `official-md3` + `platform-adaptation`.

Components define the states that apply to their behavior, including default, hover, focus, pressed, dragged, selected, activated, disabled, error, and loading where relevant.

Visual state, semantic state, and input behavior stay synchronized. Desktop implementations preserve visible keyboard focus. Touch-only affordances do not remove mouse, trackpad, keyboard, stylus, switch, or assistive-technology access when those inputs exist on the platform.

Focus and selection are modeled separately.
