# Sliders (`sliders`)

## Purpose

Select a value from a continuous or discrete range.

## Variants

- `continuous`
- `discrete`
- `range`

## States

- `default`
- `hovered`
- `focused`
- `pressed`
- `disabled`

## Token groups

`color`, `typography`, `shape`, `state`

## Accessibility

Expose minimum, maximum, current value, and keyboard or assistive-technology adjustment.
