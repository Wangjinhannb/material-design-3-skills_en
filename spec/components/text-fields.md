# Text fields (`text-fields`)

## Purpose

Enter or edit text.

## Variants

- `filled`
- `outlined`

## States

- `empty`
- `focused`
- `populated`
- `error`
- `disabled`

## Token groups

`color`, `typography`, `shape`, `state`

## Accessibility

Provide a persistent accessible name. Associate errors with the field and do not rely on color alone.
