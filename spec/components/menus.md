# Menus (`menus`)

Provenance: `official-md3` + `platform-adaptation`.

## Purpose

Present a temporary set of actions or options.

## Variants

- `dropdown`
- `contextual`

## States

- `default`
- `hovered`
- `focused`
- `pressed`
- `disabled`

## Tokens

`color`, `typography`, `shape`, `state`

## Accessibility

Use platform menu semantics and handle arrow keys, Escape, and focus return correctly.
