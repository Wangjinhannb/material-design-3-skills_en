# Snackbars (`snackbars`)

## Purpose

Provide brief feedback and, when useful, one related action.

## Variants

- `single-line`
- `two-line`
- `with-action`

## States

- `default`

## Token groups

`color`, `typography`, `shape`, `state`

## Accessibility

Do not move focus when a snackbar appears. Persistent errors need a persistent accessible message.
