# Radio button (`radio-button`)

## Purpose

Select one option from a mutually exclusive group.

## Variants

- `unselected`
- `selected`

## States

- `unselected`
- `selected`
- `hovered`
- `focused`
- `pressed`
- `disabled`

## Token groups

`color`, `typography`, `shape`, `state`

## Accessibility

Expose the group relationship and radio selection state.
