# Tabs (`tabs`)

## Purpose

Switch between related views at the same hierarchy level.

## Variants

- `primary`
- `secondary`

## States

- `default`
- `hovered`
- `focused`
- `pressed`
- `disabled`

## Token groups

`color`, `typography`, `shape`, `state`

## Accessibility

Use equivalent tablist, tab, and tabpanel semantics and keyboard behavior on the target platform.
