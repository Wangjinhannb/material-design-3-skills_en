# Date pickers (`date-pickers`)

## Purpose

Select a date or date range.

## Variants

- `docked`
- `modal`
- `range`

## States

- `default`
- `hovered`
- `focused`
- `pressed`
- `disabled`

## Token groups

`color`, `typography`, `shape`, `state`

## Accessibility

Date cells need full date names, selected state, and keyboard navigation.
