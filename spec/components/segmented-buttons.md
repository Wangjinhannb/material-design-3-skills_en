# Segmented buttons (`segmented-buttons`)

## Purpose

Switch between a small set of mutually exclusive or multi-select options.

## Variants

- `single-select`
- `multi-select`

## States

- `default`
- `hovered`
- `focused`
- `pressed`
- `disabled`

## Token groups

`color`, `typography`, `shape`, `state`

## Accessibility

Expose the group relationship and selected state.
