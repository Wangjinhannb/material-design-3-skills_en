# Divider (`divider`)

## Purpose

Separate content without introducing a strong container.

## Variants

- `full-width`
- `inset`

## States

- `default`

## Token groups

`color`, `typography`, `shape`, `state`

## Accessibility

Purely visual dividers should not create unnecessary accessibility nodes.
