# Buttons (`buttons`)

## Purpose

Trigger a clear action.

## Variants

- `elevated`
- `filled`
- `filled-tonal`
- `outlined`
- `text`

## States

- `default`
- `hovered`
- `focused`
- `pressed`
- `disabled`

## Token groups

`color`, `typography`, `shape`, `state`

## Accessibility

Accessible names must describe the action. State must not rely on color alone.
