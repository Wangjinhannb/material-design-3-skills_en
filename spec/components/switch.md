# Switch (`switch`)

Provenance: `official-md3` + `platform-adaptation`.

## Purpose

Toggle a binary setting immediately.

## Variants

- `off`
- `on`

## States

- `off`
- `on`
- `hovered`
- `focused`
- `pressed`
- `disabled`

## Tokens

`color`, `typography`, `shape`, `state`

## Accessibility

The label names the setting being changed and exposes the on/off state.
