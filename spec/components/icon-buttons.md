# Icon buttons (`icon-buttons`)

## Purpose

Expose common actions in a compact icon control.

## Variants

- `standard`
- `filled`
- `filled-tonal`
- `outlined`
- `toggle`

## States

- `default`
- `hovered`
- `focused`
- `pressed`
- `disabled`

## Token groups

`color`, `typography`, `shape`, `state`

## Accessibility

Icon buttons require an accessible name and an adequate target size.
