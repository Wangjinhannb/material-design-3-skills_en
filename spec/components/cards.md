# Cards (`cards`)

## Purpose

Group related content and actions in one container.

## Variants

- `elevated`
- `filled`
- `outlined`

## States

- `default`
- `hovered`
- `focused`
- `pressed`
- `disabled`

## Token groups

`color`, `typography`, `shape`, `state`

## Accessibility

Treat the whole card as one interactive target only when the entire card performs one action.
