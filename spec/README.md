# Specification

This directory defines the repository's Classic Material Design 3 baseline.

- `foundations/` — color, typography, shape, elevation, states, motion, layout, iconography, and normative language.
- `components/` — the 31 registered component specifications.
- `adaptive/` — window and input adaptation.
- `accessibility/` — core accessibility, internationalization, and test guidance.
- `platform-adaptation/` — rules for preserving M3 semantics on non-M3-native platforms.

Source class and platform status are recorded separately from design guidance so repository conventions are not confused with Google requirements.
