# Accessibility

Accessibility is part of component behavior and platform implementation.

- Provide accessible names, roles, values, and states.
- Preserve visible keyboard focus.
- Keep interactive targets usable for touch and alternative input.
- Support platform text scaling and dynamic type.
- Respect reduced-motion and high-contrast settings where the platform exposes them.
- Pair color with text, iconography, shape, or semantics when state must be understood.
- Keep focus order and reading order predictable.
- Associate form errors and supporting text with their controls.

Platform references document the API used to expose these semantics.
