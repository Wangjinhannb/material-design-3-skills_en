# Internationalization and Localization

Reference implementations account for:

- left-to-right and right-to-left layout;
- bidirectional text;
- CJK line breaking and font fallback;
- long translated labels and text expansion;
- locale-aware dates, numbers, and currency;
- platform text scaling and dynamic type.

The reference app uses English as its primary copy and keeps test cases for Simplified Chinese and an RTL locale in the accessibility/localization plan.
